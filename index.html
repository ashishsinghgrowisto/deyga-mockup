Deyga Organics — interactive mockup

A self-contained, offline-ready replica of deyga.in built from the live site’s real catalogue (136 products), imagery, navigation and brand tokens. Every page below is linked; the header, mega menus, mini-cart, wishlist and search work across all of them.

HomeHero slideshow, category rail, offer zone, tabbed best-sellers, concern mosaic, testimonials, awards & press.Collection / PLPCategory strip slider, live filters, sort, product grid, mobile filter & sort bottom sheets.Product / PDPGallery with capped thumb rail, variant packs, offers, accordions, FAQs, reviews, sticky add-to-bag.CartFull cart page plus the mini-cart drawer that opens from every cart icon on every page.SearchLive client-side search across all 136 products, plus the header search overlay.WishlistHeart any product anywhere — saved in localStorage and rendered here with a live badge.
Toggle Desktop / Mobile from the bar at the top of any page to check responsive behaviour. Cart and wishlist state persists in your browser via localStorage. Checkout, login and reviews are intentionally inert — this is a front-end mockup, not a store.
